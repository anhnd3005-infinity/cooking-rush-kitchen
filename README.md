## Features
- **Authentic Kitchen Workstations**:
  - **Order Ticket Board**: Live ticking customer orders (Bistro Deluxe Burger, Rustic Pepperoni Pizza, Tonkotsu Craft Ramen) with patience bars and rush-hour multipliers.
  - **Pantry Bins**: 12 fresh ingredients (brioche buns, raw beef patties, cheddar, vine tomatoes, lettuce, pizza dough, marinara, mozzarella, pepperoni, ramen noodles, broth, chashu pork).
  - **End-Grain Chopping Board**: Interactive knife chopping mechanics with flying diced slices and progress tracking.
  - **Cast Iron Sizzle Griddle**: Dual burner stations with doneness rings, steam, and sizzling grease particle effects.
  - **Ceramic Plating Station**: Layer-by-layer culinary dish assembly.
  - **Brass Service Bell**: Instant order evaluation, speed tips, and combo score streaks.
- **100% Offline Procedural Web Audio**: Real-time synthesized cutting board thuds, sizzling pan noise, and bell chimes with zero external sound files.

## Play Locally

```sh
node serve.ts
```
Then open `http://localhost:8080` in any desktop browser.
